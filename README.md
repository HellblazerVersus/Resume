# Resume

This repository contains my resume, written in LaTeX, demonstrating my ability to manage document generation as code.

You can view the compiled PDF directly here: [Vishesh_Sinha_Resume.pdf](./Vishesh_Sinha_Resume.pdf)

## Building from source

If you want to compile the `.tex` source file yourself, you will need a LaTeX distribution installed. You can compile it using `pdflatex`:

```bash
pdflatex Vishesh_Sinha_Resume.tex
```
